
# Python Basics

## Variables

Python variables store values. You can assign an integer
using `age = 20` or a string using `name = "Alice"`.

## Functions

Functions are reusable blocks of code defined using the
`def` keyword. Functions can accept arguments and return
results.

## Virtual Environments

A Python virtual environment isolates project dependencies.
Use `python -m venv .venv` to create one and activate it
before installing packages.

## Error Handling

Python uses `try` and `except` blocks to handle exceptions.
This lets programs respond to errors without immediately
crashing.
